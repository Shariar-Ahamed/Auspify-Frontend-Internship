# Task 06: Modern Web Application Dashboard

## 📌 Project Overview
Develop an enterprise-grade analytics dashboard application using modern frontend technologies (React.js, Vite, Chart libraries) as part of the Auspify Technologies Frontend Developer Internship Program.

- **Difficulty Level:** Advanced
- **Technologies Used:** React.js, Vite, CSS Modules / Vanilla CSS, Lucide Icons, Chart.js / Recharts

---

## 🎯 Key Features
- [ ] **Dashboard Layout:** Collapsible sidebar navigation, top navigation header with user profile and quick actions.
- [ ] **Analytics & Metric Widgets:** Stat cards showing KPIs (revenue, users, conversions, growth).
- [ ] **Interactive Data Charts:** Visualized trends with interactive line/bar/doughnut charts.
- [ ] **Data Table with Actions:** Recent activity / transactions list with filtering and search.
- [ ] **Dark / Light Theme:** Modern theme switcher support.
