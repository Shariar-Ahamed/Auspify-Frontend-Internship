# Task 04: Weather Dashboard Using API

## 📌 Project Overview
Build a real-time weather dashboard application that fetches and displays live weather data from an external REST API as part of the Auspify Technologies Frontend Developer Internship Program.

- **Difficulty Level:** Medium
- **Technologies Used:** HTML5, CSS3, JavaScript (Fetch API, Async/Await, JSON Handling)

---

## 🎯 Key Features
- [ ] **REST API Integration:** Fetch real-time weather metrics (temperature, humidity, wind speed, condition).
- [ ] **Search by Location:** Instant city or location search functionality.
- [ ] **Dynamic Weather UI:** Dynamic background or icons reflecting current weather conditions.
- [ ] **Error & Validation Handling:** Graceful error messages for invalid city names or network issues.
