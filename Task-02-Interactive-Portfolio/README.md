# Task 02: Interactive Portfolio Website

## 📌 Project Overview
Build a personal portfolio website showcasing projects, skills, and achievements with smooth navigation and interactive animations as part of the Auspify Technologies Frontend Developer Internship Program.

- **Difficulty Level:** Easy
- **Technologies Used:** HTML5, CSS3, JavaScript (ES6)

---

## 🎯 Key Features
- [ ] **Hero Section:** Introduction, professional title, and resume download/contact buttons.
- [ ] **About & Skills:** Interactive skills showcase with badges or progress indicators.
- [ ] **Projects Showcase:** Interactive portfolio gallery with live demo and GitHub links.
- [ ] **Interactive Contact Form:** Responsive contact form with client-side validation.
- [ ] **Smooth Scrolling & Animations:** Micro-interactions, hover effects, and CSS transitions.
