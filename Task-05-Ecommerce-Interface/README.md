# Task 05: E-Commerce Product Interface

## 📌 Project Overview
Create a modern, component-driven e-commerce product interface with dynamic product listings, search, category filtering, and an interactive shopping cart as part of the Auspify Technologies Frontend Developer Internship Program.

- **Difficulty Level:** Advanced
- **Technologies Used:** HTML5, CSS3, JavaScript (ES6+, DOM Manipulation, LocalStorage)

---

## 🎯 Key Features
- [ ] **Product Catalog:** Responsive grid layout showcasing product cards with pricing, ratings, and imagery.
- [ ] **Search & Multi-Category Filters:** Live search and category/price filtering functionality.
- [ ] **Interactive Shopping Cart:** Add to cart, quantity increment/decrement, remove items, and dynamic price calculations.
- [ ] **Cart Drawer / Modal:** Smooth slider or popup modal displaying selected cart items.
