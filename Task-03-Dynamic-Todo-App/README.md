# Task 03: Dynamic To-Do Application

## 📌 Project Overview
Develop an interactive task management application using pure JavaScript with persistent browser storage (LocalStorage) as part of the Auspify Technologies Frontend Developer Internship Program.

- **Difficulty Level:** Medium
- **Technologies Used:** HTML5, CSS3, JavaScript (DOM Manipulation, LocalStorage)

---

## 🎯 Key Features
- [ ] **Task Creation & Deletion:** Quickly add and remove to-do items.
- [ ] **Task Status Tracking:** Mark tasks as completed, pending, or active with filters.
- [ ] **LocalStorage Persistence:** Store and retrieve tasks so data remains intact across page refreshes.
- [ ] **Responsive & Modern UI:** Clean user interface with intuitive controls and feedback.
